# Cola dos comandos do Claude

> Os comandos com "/" que funcionam de verdade no Claude Code, para que serve cada um e um exemplo pronto para copiar.

*Digite **/** na caixa do Claude: aparece a lista. Comece a escrever o nome que ela filtra. Depois do nome, escreva o seu pedido.*

```
┌────────────────────────────────────────────────┐
│ /nov                                           │
├────────────────────────────────────────────────┤
│ ▸ /novidades      Radar de novidades de IA     │
└────────────────────────────────────────────────┘
```

## Os da VZ (criados para nós)

| Comando | Para quê | Exemplo |
|---|---|---|
| `/novidades` | O que saiu de novo em IA nos últimos 7 dias, em tabela, com o que serve para a VZ | `/novidades vídeo` |
| `/analisar-reel` | Assiste a um reel do Instagram e separa verdade, propaganda e o que usar | `/analisar-reel https://instagram.com/reel/...` |

## Para pensar e organizar

| Comando | Para quê | Exemplo |
|---|---|---|
| `/grill-me` | O Claude te sabatina com perguntas (com a recomendação dele) até o plano ficar redondo | `/grill-me proposta da influenciadora` |
| `/handoff` | Resume a conversa num documento para continuar em outra sessão ou no outro PC | `/handoff amanhã vou criar o agente da noite` |
| `/find-skills` | Procura uma skill pronta para uma tarefa (revisar antes de instalar!) | `/find-skills edição de vídeo` |

## Para sistemas e sites

| Comando | Para quê | Exemplo |
|---|---|---|
| `/design-taste-frontend` | Visual profissional, sem "cara de IA" | `/design-taste-frontend tela de login do ScanTE` |
| `/redesign-existing-projects` | Repaginar um site ou sistema que já existe | `/redesign-existing-projects o painel do ContabIA` |
| `/web-design-guidelines` | Revisar acessibilidade e boas práticas | `/web-design-guidelines` |
| `/code-review` | Revisar o código antes de subir | `/code-review` |
| `/security-review` | Procurar falhas de segurança | `/security-review` |
| `/graphify` | Mapa de um projeto: como tudo se liga | `/graphify` |

## Para automatizar

| Comando | Para quê | Exemplo |
|---|---|---|
| `/schedule` | Agendar um agente na nuvem (ex.: o agente da noite) | `/schedule todo dia às 2h no central-vz…` |
| `/loop` | Repetir uma tarefa de tempos em tempos enquanto o Claude está aberto | `/loop 30m confere se o site está no ar` |

## Do próprio Claude Code

| Comando | Para quê |
|---|---|
| `/model` | Trocar de modelo (Opus, Sonnet…) |
| `/clear` | Começar uma conversa limpa |
| `/compact` | Resumir a conversa para ela durar mais |
| `/plugin` | Ver e instalar plugins (ex.: HyperFrames) |
| `/mcp` | Ver as conexões (Chrome, banco de dados…) |
| `/memory` | Ver o que o Claude guardou |

## Cuidado: comandos que não existem

Reels prometem "códigos secretos" como `/ghost`, `/godmode` e `/L99`. **Eles não existem.** O Claude só entende a palavra. O que funciona é pedir com clareza: "responda como especialista, direto, sem explicação básica".

## Pedir sem comando também vale

Você não precisa decorar nada: "deixa o visual dessa tela profissional" funciona. O comando só garante que o Claude use o método certo.
